## 日期：2026-08-29

## DRV8323 当前异常记录

### 已确认正常

* SPI 读写正常
* 5 个默认寄存器读取正确
* TIM1 六路 PWM、死区、计数正常
* `DRV_EN=1`、PWM 未启动时：

  ```text
  FAULT1 = 0x000
  FAULT2 = 0x000
  ```

### PWM 启动后异常

无电机、三相同相 PWM 测试后：

```text
FAULT1 = 0x0500
FAULT2 = 0x0022
```

对应：

* Gate Drive Fault
* A 相高侧 VGS Fault
* C 相高侧 VGS Fault

### 断电测量

```text
GHA-SHA ≈ 7 MΩ
GHB-SHB ≈ 0.4 MΩ
GHC-SHC ≈ 1.7 Ω
```

其中 **C 相高侧 GHC-SHC 仅 1.7 Ω，明显异常**。

C 相高侧 D-S 二极管测试：

```text
SHC → VIN ≈ 0.47 V
反向 → OL
```

### 当前判断

重点怀疑：

```text
1. C相高侧 MOSFET G-S 损坏
或
2. DRV8323 的 GHC/SHC 驱动通道损坏
```

### 下一步

暂时停止 PWM 测试，先隔离 C 相高侧 MOSFET，再分别测：

```text
MOSFET Gate-Source
板端 GHC-SHC
```

以确定故障来自 MOSFET 还是 DRV8323。
